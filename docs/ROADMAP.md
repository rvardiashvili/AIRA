# AIRA Roadmap

## ✅ Completed Features
- [x] **Core UI:** Minimalist centered bar with smooth animations.
- [x] **Local AI:** Seamless integration with Ollama.
- [x] **Advanced RAG:** Switch to ChromaDB for scalable vector search.
- [x] **History Manager:** SQLite-backed multi-session support.
- [x] **System Tools:** App launching, process management, clipboard, etc.
- [x] **Disk Indexer:** Recursive folder indexing with file manager context menus.
- [x] **Theme System:** Support for Dark, Light, and Nord themes.
- [x] **User Profiles:** Automatic detection and manual customization.

## 🚀 Future Enhancements
- [ ] **AI Evolution:** Style-learning based on long-term interactions.
- [ ] **Plugin API:** Modular system for users to add their own Python tools.
- [ ] **Voice Support:** High-quality local TTS/STT (Optional lightweight module).
- [ ] **Web Dashboard:** Remote management of AIRA memory.
- [ ] **Multi-Model Pipeline:** Using different models for different tasks (vision vs. reasoning).
