# AIRA Development Plan

## Phase 1: Core Foundation (Completed)
- [x] Minimalist PyQt6 GUI.
- [x] Ollama integration for local LLMs.
- [x] Tool-calling framework.
- [x] Basic persistent history (SQLite).
- [x] Basic semantic memory (RAG with SQLite).

## Phase 2: Refinement & Advanced RAG (Completed)
- [x] Transition to ChromaDB for scalable vector search.
- [x] Object-Oriented refactor of the whole project.
- [x] Dynamic system-based user profile detection.
- [x] Incremental Markdown rendering for streaming.
- [x] Control Panel for personas, history, and memory.

## Phase 3: System Integration (Completed)
- [x] Disk indexing tools.
- [x] File Manager extensions (Nautilus, Nemo, Dolphin).
- [x] Standardized user data location (~/.local/share/aira).
- [x] Comprehensive theme system (Dark, Light, Nord).

## Phase 4: Intelligence & Growth (In Progress)
- [ ] **AI Evolution:** Style-learning based on user habits.
- [ ] **Multi-Modal Workflows:** Better use of Vision for complex tasks.
- [ ] **Plugin Ecosystem:** Easy installation of third-party tools.
- [ ] **Cross-Platform Installer:** Better packaging for various Linux distros.
